# lueya v0.4.0 — bounded signed-source playback recovery

This release extends the **experimental native online player** without
changing its approved warm-glass appearance.

- Retry an expiring signed media source during playback: HTTP 410, or
  HTTP 403 only after the conservative source lifetime has elapsed.
- Resolve again through the *current user's* Keychain-backed session,
  retaining the track ID, codec and quality.
- Back off before renewal, cap renewals to six for the playing asset
  and retry each failed byte range at most once. Reject a changed
  media length, untrusted CDN source, redirected response or denial.
- Avoid reading oversized HTML denial bodies as if they were media.
  All approved 206 audio responses remain strictly capped at 128 KiB.
- New original generated-AAC native AVAsset resource-loader tests exercise
  206 range delivery, expiry, redirect rejection and cancellation/seek.
  Both macOS 26 and Xcode 27 CI must pass before this release is published.

No offline/download feature, DRM bypass, media disk cache, tokens passed
to CDN hosts, external dependencies or animation/design changes.
