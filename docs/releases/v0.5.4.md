# lueya v0.5.4 — clearer catalog and stable interaction

Owner feedback on signed v0.5.3:
- Removed scrolling did not solve unresponsive buttons whenever the pointer
  was over results. The owner preferred the original scroll experience.
- The player still shows dark areas around the edges.
- The official Yandex Music screenshot demonstrates a simpler combined
  search with artists first and song matches alongside.

## Changes

- One search with default **All** results: artist matches first, then songs.
  **Songs** and **Artists** are optional filters, not prerequisites.
- Selecting an artist opens that artist's own tracks; Back returns to the
  previously loaded artist results.
- Restore a scrollable results pane without row paging.
- Fix signed-in MenuBarExtra content height to avoid changing the window's
  hit-testing region when opening results. Use plain full-width hit areas and
  eliminate hover scaling from interactive button targets.
- Fill the entire native window background in matching warm tones, instead
  of leaving dark material visible in corners.
- Preserve existing playback pipeline, Keychain account/service, signing
  certificate, OAuth flow, no-offline policy and artwork security controls.

## Verification and caveats

CI validates compilation, tests, arm64 packaging, signature and archive
checks on macOS 26 and Xcode 27. The root cause of macOS pointer behavior
is inferred from the prior reports and SwiftUI layout; only owner-device
testing can confirm that clicks and window edges are now correct.
The independent stream-source 403 limitation remains unchanged.
