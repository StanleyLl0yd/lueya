# lueya v0.1.1 — clearer track-source diagnostics

Maintenance update for the lightweight Apple Silicon macOS client.

- Diagnoses which authenticated API request was rejected:
  **track metadata** or **audio source**, including the requested
  audio quality.
- Distinguishes HTTP 401, 403, 429 and unexpected HTTP statuses.
  Error messages never disclose OAuth tokens, request bodies or
  signed media URLs.
- Adds synthetic regression tests for metadata and source rejection.
- Preserves the compact arm64-only build and immutable, versioned
  GitHub Release ZIP with SHA-256 checksums.

The earlier `HTTP 403` remains **unresolved** until a real-device
retest. An HTTP 403 response does not prove a regional block.

**This early release does not yet play music.** The full-track playback
and provider-authorization requirements of M0 remain open.
No offline mode or DRM circumvention is supported.

To test, sign into your own Yandex account and check numeric track ID
`99338938`. Report the safe diagnostic message only; never include
passwords, active device codes, access/refresh tokens or signed media URLs.

Requires Apple Silicon with macOS 26 or later. The build is ad-hoc
signed and is not yet notarized. Use macOS's normal security controls;
do not disable Gatekeeper.
