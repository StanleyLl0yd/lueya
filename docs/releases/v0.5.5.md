# lueya v0.5.5 — album and artist navigation

Owner feedback on v0.5.4:
- Artist browsing displays only a short list of popular tracks.
- Artist discographies should expose albums and singles.
- The player should display the album and let the listener click artist or album
  metadata to browse the corresponding tracks.

## Changes
- Unified search now covers artists, albums and songs. Optional Albums filter.
- Artist view separates popular tracks and albums/singles, with a "More albums"
  control for additional bounded pages.
- Album view displays a full disc-ordered track list, capped to 150 entries
  per request for resource safety.
- The player shows the album title when authenticated catalog metadata contains
  a validated album ID. Clicking artist or album navigates to its own page.
  Artist names without validated IDs open artist search for explicit selection
  rather than guessing which identity is intended.
- Nested Back restores the artist page, or the original search results.
- No changes to signing identity, Keychain, OAuth or the audio transport.

## Validation
- New synthetic tests cover album search, artist discography paging,
  multi-disc album tracks, metadata and malformed IDs.
- Exact-head macOS 26 and Xcode 27 CI must pass before one-shot signed release.
- CI is not equivalent to live Yandex Music API verification. Owner testing
  must confirm endpoint compatibility and native navigation in the window.
- Album cover requests retain the existing HTTPS allowlist.
- Music remains online only. No DRM circumvention or catalog persistence.
