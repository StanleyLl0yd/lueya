# lueya v0.1.0 — early-access release

First regular versioned release of the lightweight native macOS companion.

- Native warm-glass menu-bar interface for Apple Silicon.
- User-owned Yandex account sign-in and local Keychain session management.
- Experimental online track metadata and source availability diagnostic;
  reports separate HTTP 403, metadata-unavailable and missing-source states.
- Arm64-only size-optimized packaging, sandbox signing and CI validation
  on macOS 26 and Xcode 27.
- Separate English and Russian README files with direct versioned ZIP links.
- Permanent GitHub Release assets and Semantic Versioning.

**This is not yet a functioning audio player.** No in-app playback, search,
playlists, My Wave or offline feature. The provider interface is unofficial,
may change, and account/region/subscription restrictions still apply.
A valid account or source candidate is not proof of full-length playback.

Download `lueya-0.1.0-macos-arm64.zip` and `SHA256SUMS.txt` from this release.
Verify the checksum. Apple Silicon / macOS 26+ required. This build is
**ad-hoc signed, not notarized**: do not disable Gatekeeper; after verifying
the file use the operating system's Open Anyway option if offered.

Please do not post OAuth tokens, passwords, live device codes, media signatures
or personal account URLs in bug reports.

The release is distributable for early evaluation, but M0 technical acceptance,
full-track playback and provider distribution rights remain open.
