# lueya v0.3.0 — experimental native online playback

This is the first **experimental** macOS playback build, not proof that
complete tracks are playable using the unofficial Music interface.

## What is new

- User-initiated online playback for a compatible raw AAC or MP3 source
  found under each user's own Yandex Music account.
- Native AVPlayer with Play / Pause / Stop / Seek controls, elapsed
  time display and refresh of an expired candidate before replay.
- The signed CDN address is never given to AVPlayer. A private
  AVAssetResourceLoader delivers bounded memory-only data blocks.
- HTTP Range requests: HTTPS-only provider CDN allowlist, no-follow
  redirects, exact response origin, Content-Range, length and MIME
  verification. Maximum 128 KiB per request.
- No OAuth header or browser cookies passed to the media CDN.
  No disk-persisted audio, offline downloads or DRM circumvention.
- Swift 6 native Apple Silicon app, existing warm matte-glass UI,
  optimized build and permanent versioned ZIP download.

## Real-world verification still required

The earlier physical Mac test of Yodelice — Fade Away, ID
`99338938`, returned a compatible `aac-mp4 / hq` candidate, but
**did not retrieve or play audio**. The first playback implementation
must be tested for >30 seconds, to actual completion, pause/seek,
restart, link expiry, network interruptions and error recovery.

Strict security policy may reject a genuine CDN that redirects or
does not return verifiable byte ranges. That must be investigated
before changing network restrictions; it is not grounds to disable
the checks.

The provider can restrict playback and independent distribution.
A subscription or technical access alone is not a license to make
a general third-party player. M0 remains OPEN until those terms,
real playback and the full repository-wide audit are resolved.

## Installation and feedback

Download `lueya-0.3.0-macos-arm64.zip` plus `SHA256SUMS.txt`.
Apple Silicon, macOS 26 or newer. Ad-hoc signed, not notarized.
Verify the checksum. Use the normal macOS Open Anyway approval only
if offered; do not turn off Gatekeeper.

For the trial: sign in, enter track ID `99338938`, Check, then Play.
Report whether audio starts, plays past 30 seconds, reaches its normal
ending, and whether Pause, Seek, Stop and Replay work. Safe on-screen
error text is useful; OAuth tokens, active device codes, passwords,
signed CDN addresses and network request logs containing credentials
must **not** be shared.
