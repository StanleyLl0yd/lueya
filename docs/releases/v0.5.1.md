# lueya v0.5.1 — signed feedback-driven test build

The owner reported that v0.5.0 did not visibly search for "кино" and
that the earlier tactile button animations seemed absent. This release
addresses both issues without changing the authenticated streaming engine.

- Search triggers automatically 450 ms after the last edit, while Enter
  and the arrow still submit immediately.
- A new query invalidates stale search state; progress, no results,
  failures and manual retry are visible.
- The authenticated search provider retries with all-category results
  when a track-only query returns no matches, to better handle artist names.
- Every button, including player navigation, search, result rows, Sign out,
  and Quit, shares spring hover/press animation based on the v0.4.1 feel;
  Reduce Motion remains supported.
- Synthetic regression coverage includes a Cyrillic artist-name fallback.
- No offline mode, local media catalog, third-party dependencies, streaming
  rights assertions, or changes to the OAuth/Keychain security model.

Target: Apple Silicon arm64, macOS 26+; certificate-signed using the
protected persistent self-signed research identity. Not notarized by Apple
or signed with Apple Developer ID.
