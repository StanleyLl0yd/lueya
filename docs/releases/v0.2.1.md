# lueya v0.2.1 — refined zen motion

A focused visual patch for the existing native warm matte-glass interface.

- Restores a more expressive yet restrained feel: the hero waveform and
  concentric halo gently breathe while the menu is visible.
- Adds a short, soft content entrance, spring-like hover responses for
  the music link and source check, and smoother source-status changes.
- Respects macOS **Reduce Motion**: no breathing animation, hover movement
  or animated transitions when enabled.
- Stops the repeating motion when the menu disappears to avoid idle
  animation work; layout, cream/champagne palette and version footer
  are unchanged.
- The optimized arm64-only build remains free of third-party runtime
  dependencies; downloadable file name is
  `lueya-0.2.1-macos-arm64.zip`, with a separate SHA-256 manifest.

**Early-access limitation:** lueya can sign in using an individual
account and check candidate online raw sources, but it cannot play
audio yet. Source discovery in v0.2.0 has been observed for
Yodelice — Fade Away, with `aac-mp4 / hq`; this does not verify
audio bytes, licensing, entitlement, or full-length playback.
There is no offline download and no DRM circumvention.

Requires Apple Silicon and macOS 26 or later. The app is ad-hoc
signed and not notarized. Verify SHA-256 and use the normal macOS
security controls when opening it. Do not disable Gatekeeper.
Do not share OAuth tokens, live device codes, or signed media links.
