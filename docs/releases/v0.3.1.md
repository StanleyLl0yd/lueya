# lueya v0.3.1 — reliable playback startup diagnosis

Targeted stabilization of the v0.3.0 experimental native player.

- Observe native AVPlayerItem failure and AVPlayer time-control status
  directly, including errors that occur before the first playback tick.
- A cancellable 15-second startup watchdog prevents indefinite
  "Connecting…" with no feedback; pausing, stopping or changing tracks
  cancels stale operations.
- Guard against errors reported by an already-replaced audio asset.
- Keep all AVFoundation system error descriptions private: media URLs may
  include signatures and must never be shown or logged.
- Existing Play/Pause/Stop/Seek and strict, bounded online streaming
  remain intact. No files, offline mode, DRM circumvention or new
  dependencies.
- Apple Silicon, macOS 26+, optimized arm64 build,
  `lueya-0.3.1-macos-arm64.zip` with SHA-256 verification.

**This is still an experimental player.** The source candidate for
track 99338938 has been observed on a Mac, but full audio delivery
past 30 seconds and complete-track playback have not been verified.
A subscription and technical integration are not proof of independent
distribution rights. M0 remains OPEN.

To test: sign in with your account, check track 99338938 and use Play.
Report only whether it starts, reaches 30 seconds and the end, whether
Pause/Seek/Stop work, and any on-screen redacted failure message.
Never provide access tokens, browser cookies, live device codes or
