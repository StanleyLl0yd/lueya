# lueya v0.2.0 — warm matte glass

A compatible visual and online source-selection improvement for the native
Apple Silicon macOS early-access app.

## Highlights

- A redesigned menu-bar interface with warm cream/champagne tones, authentic
  native macOS translucent material, matte tint, soft ambient light and
  generous breathing room.
- Delicate hover transitions, with accessibility support for Reduce Motion
  and Reduce Transparency (no continuously running decorative animation).
- The bottom-left footer always displays the actual version from the
  application's signed Info.plist.
- For experimental authenticated online raw-source lookup, a
  quality-specific HTTP 403 may fall back to the next lower requested
  quality. Authentication failures and rate limits remain terminal.
  No encrypted `encraw`, offline playback or DRM circumvention.
- Optimized native arm64-only binary, permanent, versioned Release ZIP
  `lueya-0.2.0-macos-arm64.zip` and SHA-256 checksum.

## Limitations

**This is still an early-access app and does not play music yet.**
OAuth sign-in and Keychain sessions exist, but real full-track playback,
playback controls, search, libraries and My Wave are not implemented.
The unofficial Music integration can be denied by the provider, and
reaching a raw-source URL does not prove distribution permissions,
subscriber entitlement or successful playback.

The user's earlier track `99338938` failed at `audio source (hq)`
with HTTP 403 in v0.1.1. v0.2.0 can test whether a separately permitted
lower-quality raw source exists; this is not a confirmed fix of the
provider refusal.

Requires macOS 26 or newer and Apple Silicon. Ad-hoc signed and not
notarized. Verify the SHA-256 and use macOS's normal security approval
when necessary; do not disable Gatekeeper.

Do not share OAuth credentials, active device codes, signed media URLs,
browser cookies or private account information in issue reports.
