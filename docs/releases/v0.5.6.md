# lueya v0.5.6 — Explore and My Wave

## What changed

- **Explore is now home.** It shows the most recently played track from the signed-in
  Yandex Music account and a short recent-listening list. The latest item can be
  played again with one click.
- **My Wave.** Start Yandex Music's personalized radio explicitly from Explore.
  lueya creates an authenticated radio session, plays its returned tracks through
  the existing online player, fetches later batches as needed, and sends only the
  playback events needed for recommendations (radio/track start, finish and skip).
- **Search has its own screen.** Songs, Albums and Artists are separate categories.
  Songs use compact rows; albums and artists have larger artwork and clearer
  identity. The mini-player stays visible while browsing.
- **A separate Player screen** keeps full playback controls available without
  forcing the player to be the start page.
- **No autoplay.** Launching the app, loading history or showing My Wave does not
  start audio. The listener explicitly chooses a recent track or starts My Wave.

## Boundaries

- Recent history and My Wave use authenticated Yandex Music API endpoints.
  This is an experimental integration with an unofficial API surface, not an
  official Yandex client or endorsement.
- Radio feedback is sent to Yandex Music only for the active radio session.
  lueya does not operate an application backend or analytics service.
- OAuth credentials remain in macOS Keychain. History, recommendations and
  artwork remain in memory; no offline audio or persistent music catalog.
- No DRM circumvention, scraping, or offline downloading is introduced.
- The provider's current terms/permissions and real-account API compatibility
  remain open questions; CI mocks do not prove live service behavior.
