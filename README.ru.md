# lueya

**Музыка без лишнего шума.**

[English](README.md) · **Русский**

lueya («лу-э-я») — минималистичное нативное приложение для macOS,
создаваемое как компактный, спокойный клиент Яндекс Музыки.
Проект независимый и неофициальный.

## Что уже работает

- Воздушный интерфейс в строке меню: тёплое матовое стекло, мягкий свет и деликатная анимация.
- Авторизация в собственном аккаунте Яндекса через код на странице входа.
- Безопасное хранение, восстановление и удаление сессии через Связку ключей macOS.
- Онлайн-воспроизведение AAC/MP3: запуск, пауза, остановка, перемотка, громкость и обновление истекающих ссылок.
- Поиск песен и исполнителей, выбор композиции, временная очередь треков с переключением вперёд и назад.

**v0.5.0 — кандидат на тестирование:** компактный музыкальный плеер,
единые анимации всех кнопок (включая Sign out), поиск и очередь.
Пользователь подтвердил работу звука на v0.4.1. Поиск, переключение
композиций и регрессии ещё требуют проверки на Mac. Плейлисты и
«Моя волна» пока недоступны. Работа с неофициальным API не означает
разрешения поставщика сервиса.

Требуется Mac с **Apple Silicon** и **macOS 26 или новее**
(macOS 27 поддерживается). Приложение подписано для тестирования,
но пока **не нотарифицировано Apple**. macOS может заблокировать
запуск. После проверки контрольной суммы используй системный раздел
«Конфиденциальность и безопасность» → «Открыть всё равно»,
если такая возможность предложена. Отключать Gatekeeper не нужно.

## Лёгкость и приватность

Swift 6, SwiftUI и AppKit. Никаких Electron, рекламы, собственной
аналитики, сервера для логинов и сторонних runtime-зависимостей.
Каждый пользователь авторизуется самостоятельно. **Музыка только онлайн:**
без офлайн-загрузок и постоянного хранения аудио.
